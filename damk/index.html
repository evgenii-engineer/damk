DAMK — artist

DAMK is a Lisbon-based artist working with concrete, plaster, epoxy, tin, urban objects, and monkey-like characters.

· Note

One name. One quiet world.

DAMK (also written EVG DAMK or evgdamk) is a contemporary artist based in Lisbon, Portugal. The name appears on every work, every signature, and on this website at evgdamk.com.

The practice is contemporary object art — small, handmade pieces built from concrete, plaster, epoxy, tin, paint, and fragments collected from the street. Recurring across the work is a monkey-like character — a quiet, slightly clumsy figure that has become a personal motif.

Other names you may see attached to the same work: DAMK, EVG DAMK, evgdamk. They all refer to the same artist.
